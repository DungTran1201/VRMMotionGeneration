# `diagrams/context/` — Context Diagrams

## Purpose
Maintains system context diagrams illustrating the boundary between the VRM motion platform and external entities (users, 3D asset providers, external motion models).

## What Belongs Here
- System context diagrams (C4 Level 1).
- External interface boundary diagrams.

## What Must NOT Belong Here
- Low-level internal class or component diagrams.

## Source-of-Truth Relationship
- Derived from `models/context/` and `docs/00-discovery/`.
