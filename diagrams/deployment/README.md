# `diagrams/deployment/` — Deployment Diagrams

## Purpose
Visualizes container topologies, network routing, reverse proxies, and host physical infrastructure.

## What Belongs Here
- Local multi-container development deployment diagrams.
- Production hosting, ingress, and hardware acceleration (GPU) topologies.

## What Must NOT Belong Here
- Application internal class diagrams.

## Source-of-Truth Relationship
