# `diagrams/ux/` — UX Flow & Layout Diagrams

## Purpose
Maintains visual user experience wireframes, screen layout schematics, and UI navigation flow diagrams.

## What Belongs Here
- 3D viewport HUD layout schematics.
- Screen state transitions and modal dialog interaction flows.
- Avatar inspection and animation timeline control wireframes.

## What Must NOT Belong Here
- Low-level network sequence diagrams.

## Source-of-Truth Relationship
- Derived from `models/ux/` and `docs/10-ux/`.
