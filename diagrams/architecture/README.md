# `diagrams/architecture/` — Architecture Diagrams

## Purpose
Visualizes component structure, subsystem interfaces, and boundaries between frontend presentation, backend kinematic services, and infrastructure layers.

## What Belongs Here
- High-level component decomposition diagrams (C4 Level 2/3).
- Subsystem interaction diagrams.

## What Must NOT Belong Here
- Process workflows or UX mockups.

## Source-of-Truth Relationship
- Derived from `models/architecture/` and `docs/05-architecture/`.
