# `docs/02-requirements/` — Requirements Engineering

## Purpose
Specifies functional requirements (FR), non-functional requirements (NFR), user capabilities, and system constraints for the VRM motion generation platform.

## What Belongs Here
- Functional requirements specifications (avatar loading, motion playback, retargeting).
- Non-functional requirements (latency targets, framerate thresholds, browser compatibility).
- System constraints (offline mode support, memory limits).

## What Must NOT Belong Here
- Implementation source code or framework-specific configurations.
- Unverified feature claims or speculative product wishlists.

## Source-of-Truth Relationship
- Formal requirements must be mirrored in structured machine-readable form in `models/requirements/`.
