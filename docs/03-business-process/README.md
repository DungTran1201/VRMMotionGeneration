# `docs/03-business-process/` — Business Processes & Workflows

## Purpose
Documents business logic workflows, user operational procedures, avatar onboarding processes, and motion lifecycle stages.

## What Belongs Here
- High-level end-to-end user journeys (e.g., avatar import -> motion generation -> retargeting -> export).
- Humanoid asset approval and validation workflows.
- Experiment-to-production promotion processes.

## What Must NOT Belong Here
- Low-level code implementation details or language syntax.
- Machine-level binary formats.

## Source-of-Truth Relationship
- Synchronized with machine-readable process models in `models/process/` and visualized in `diagrams/processes/`.
