## 2. OWASP Security Cheat Sheets & Industry Baselines

| ID         | Cheat Sheet / Project                                          | Publisher        | URL                                                                                                                            | Primary Focus & Applied Architecture                                                                                                                           |
| :--------- | :------------------------------------------------------------- | :--------------- | :----------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **REF-08** | OWASP Authentication Cheat Sheet                               | OWASP Foundation | [OWASP Authentication](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)                         | Generic failure messaging to prevent user enumeration; progressive authentication throttling; secure credential validation.                                    |
| **REF-09** | OWASP Session Management Cheat Sheet                           | OWASP Foundation | [OWASP Session Management](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)                 | CSPRNG session IDs (128-bit entropy); session token rotation on authentication; idle (24h) and absolute (30d) timeouts; revocation on logout.                  |
| **REF-10** | OWASP Password Storage Cheat Sheet                             | OWASP Foundation | [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)                     | Mandatory Argon2id (m=64MB, t=3, p=4) or Bcrypt (cost factor >= 12) memory-hard hashing; unique salts; no reversible encryption of passwords.                  |
| **REF-11** | OWASP Forgot Password Cheat Sheet                              | OWASP Foundation | [OWASP Forgot Password](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)                       | Cryptographically secure reset tokens (>=128 bits); short TTL (15 min); single-use; generic response prevents enumeration; global and per-account rate limits. |
| **REF-12** | OWASP REST Security Cheat Sheet                                | OWASP Foundation | [OWASP REST Security](https://cheatsheetseries.owasp.org/cheatsheets/REST_Security_Cheat_Sheet.html)                           | Proper HTTP verbs; strict Content-Type validation (`application/json`); generic error envelopes without stack traces; API versioning; correlation IDs.         |
| **REF-13** | OWASP CSRF Prevention Cheat Sheet                              | OWASP Foundation | [OWASP CSRF Prevention](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html) | `SameSite=Lax/Strict` cookie attribute; custom request header (`X-CSRF-Token`); synchronized token or HMAC double-submit pattern for mutating routes.          |
| **REF-14** | OWASP Secrets Management Cheat Sheet                           | OWASP Foundation | [OWASP Secrets Management](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html)                 | Never commit secrets to Git; envelope encryption with KMS for user API keys; secret rotation lifecycle; audit trail; runtime injection via environment or KMS. |
| **REF-15** | OWASP Logging Cheat Sheet                                      | OWASP Foundation | [OWASP Logging](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html)                                       | Strict redaction of PII, passwords, reset tokens, auth cookies, and provider API keys from application logs; structured JSON logging.                          |
| **REF-16** | OWASP Abuse Case Cheat Sheet                                   | OWASP Foundation | [OWASP Abuse Case](https://cheatsheetseries.owasp.org/cheatsheets/Abuse_Case_Cheat_Sheet.html)                                 | Threat modeling for credential stuffing, bot scraping, account squatting, password reset bombing, and resource exhaustion.                                     |
| **REF-17** | OWASP Application Security Verification Standard (ASVS v4.0.3) | OWASP Foundation | [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/)                                        | Target Level 2 compliance for authentication, session management, access control, and cryptographic storage.                                                   |
| **REF-18** | OWASP Top 10 (2021)                                            | OWASP Foundation | [OWASP Top 10](https://owasp.org/www-project-top-ten/)                                                                         | Mitigations for A01:Broken Access Control, A02:Cryptographic Failures, A07:Identification and Authentication Failures.                                         |
