# `docs/00-discovery/` — Discovery & Exploratory Findings

## Purpose
Maintains discovery reports, baseline audits, environment inspections, upstream repository evaluations, and historical transition records.

## What Belongs Here
- Workspace reset and scaffold reports (such as `reset-and-scaffold-report.md`).
- Initial environment capability audits (CPU/GPU, Python runtime, operating system).
- Upstream reference analysis (e.g. NVIDIA GR00T MotionBricks structure and requirements).
- Feasibility studies and technology spike findings.

## What Must NOT Belong Here
- Approved requirements or formal architecture specifications (these belong in `02-requirements/` and `05-architecture/`).
- Scratch scripts or temporary command line dumps without analysis.

## Source-of-Truth Relationship
- Represents the baseline facts from which planning (`01-planning/`) and requirements (`02-requirements/`) are established.
