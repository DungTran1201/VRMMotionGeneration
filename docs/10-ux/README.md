# `docs/10-ux/` — User Experience & Interface Design

## Purpose
Documents user interface guidelines, 3D viewport ergonomics, camera controls, typography, color palettes, and interaction wireframes.

## What Belongs Here
- Viewport interaction guidelines (orbit, pan, zoom, bone visualization).
- Visual hierarchy, typography, and dark-mode technical styling specifications.
- Timeline scrubber behavior, status indicators, and toast notification rules.
- Mobile and desktop responsive layout guidelines.

## What Must NOT Belong Here
- CSS stylesheet files or JavaScript component implementations.
- Subjective opinions without documented design rationale.

## Source-of-Truth Relationship
- Formal design tokens and component specs are modeled in `models/ux/` and diagrammed in `diagrams/ux/`.
