# `docs/05-architecture/` — System Architecture & ADRs

## Purpose
Documents the overall system architecture, component decoupling boundaries, design patterns, and formal Architecture Decision Records (ADRs).

## What Belongs Here
- System component architecture descriptions (frontend, backend, infra).
- Architecture Decision Records (ADRs) capturing context, decision, consequences, and status.
- Integration patterns between motion sources, kinematic decoders, and avatar renderers.

## What Must NOT Belong Here
- Volatile day-to-day code diffs or minor bug fix notes.
- Direct code snippets that duplicate source repository files.

## Source-of-Truth Relationship
- Formal architecture specifications are modeled in `models/architecture/` and visualized in `diagrams/architecture/`.
