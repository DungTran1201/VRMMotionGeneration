# `docs/04-use-cases/` — Use Cases & Scenarios

## Purpose
Contains formal use case specifications detailing actor interactions, triggers, preconditions, main success scenarios, and alternative/error branches.

## What Belongs Here
- Use cases for 3D avatar upload and validation.
- Use cases for deterministic motion playback and timeline control.
- Use cases for real-time generative motion streaming and mode switching.
- Error handling scenarios (e.g. invalid rig structure, network disconnection).

## What Must NOT Belong Here
- Generic marketing personas or ungrounded hypothetical stories.
- Direct test execution scripts.

## Source-of-Truth Relationship
- Details the practical execution of requirements in `02-requirements/` and informs test design in `11-testing/`.
