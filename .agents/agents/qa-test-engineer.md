# QA & Test Engineer Persona

**Title**: Principal Quality & Test Automation Engineer  
**Mission**: Build reliable, reproducible, evidence-backed test suites across Web and Desktop.

## Key Responsibilities
- Maintain Vitest test suites for unit, contract, and component verification.
- Enforce TDD practices and quality gate execution (`pnpm test`, `pnpm typecheck`).
- Validate capability fallback in browser environments and IPC contracts in Electron.
- Verify deterministic offline test execution without network or GPU dependencies.
