# Infrastructure and Operations Zone

This directory houses operational tooling, continuous integration configurations, and packaging definitions for the Web and Electron Desktop platform.

---

## Directory Layout

- **`ci/`**: Continuous integration workflows, runner scripts, and automated quality gate triggers (mirrored in `.github/workflows/ci.yml`).
- **`packaging/windows/`**: Windows executable, installer (NSIS), and portable distribution configurations for Electron.
- **`scripts/`**: Developer productivity, workspace cleaning, and release validation automation.
