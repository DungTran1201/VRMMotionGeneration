## 1. REST Endpoints Specification

### 1.1 `GET /api/health`
Checks server vitality, GPU model, free VRAM, and checkpoint availability.

- **Response:** `200 OK`
```json
{
  "status": "ok",
  "mode": "LIVE ARDY",
  "device": "cuda:0",
  "torch_version": "2.6.0+cu124",
  "cuda_available": true,
  "gpu_name": "NVIDIA GeForce GTX 1650",
  "vram_free_mb": 2256.0,
  "checkpoint_ready": true,
  "model_name": "ARDY-Core-RP-20FPS-Horizon8",
  "active_jobs": 0
}
```

### 1.2 `GET /api/models`
Lists registered ARDY model variants and their readiness status.

- **Response:** `200 OK`
```json
{
  "models": [
    {
      "alias": "core8",
      "full_name": "ARDY-Core-RP-20FPS-Horizon8",
      "skeleton": "CoreSkeleton27",
      "fps": 20.0,
      "horizon": 8,
      "available": true,
      "description": "Official NVIDIA ARDY Core model, 20 FPS, 8-frame autoregressive horizon."
    }
  ]
}
```

### 1.3 `POST /api/generations`
Submits a text-conditioned motion synthesis job.

- **Request Body:**
```json
{
  "prompt": "A person waves both hands enthusiastically in the air.",
  "duration_seconds": 3.0,
  "model": "ARDY-Core-RP-20FPS-Horizon8",
  "seed": 42
}
```
- **Validation Rules:**
  - `prompt`: 1–500 characters, rejects whitespace-only inputs.
  - `duration_seconds`: Range 0.5 to 10.0 seconds.
- **Response:** `200 OK`
```json
{
  "job_id": "job-d41d8cd98f00b204e9800998ecf8427e",
  "status": "queued"
}
```
- **Error:** `429 Too Many Requests` if another GPU generation is currently executing.

### 1.4 `GET /api/generations/{job_id}`
Queries job progression, execution status, and final payload.

- **Response:** `200 OK`
```json
{
  "job_id": "job-d41d8cd98f00b204e9800998ecf8427e",
  "status": "completed",
  "progress_step": "complete",
  "result": { ... UnifiedMotionPayload ... },
  "error_message": null
}
```

### 1.5 `POST /api/generations/{job_id}/cancel`
Requests cancellation of a queued or active generation job.

- **Response:** `200 OK` or `400 Bad Request` if job already finished or non-existent.

### 1.6 `GET /api/samples/default`
Retrieves default startup sample motion generated by real ARDY inference (`waves.vrm.json`).

## 2. WebSocket Real-Time Events

- **Endpoint:** `WS /api/generations/{job_id}/events`
- **Protocol:** JSON message stream
- **Message Sequence:**
  1. `{"status": "processing", "progress_step": "encoding_prompt"}`
  2. `{"status": "processing", "progress_step": "diffusion_denoiser"}`
  3. `{"status": "processing", "progress_step": "decoding_tokenizer"}`
  4. `{"status": "processing", "progress_step": "retargeting_vrm"}`
  5. `{"status": "completed", "result": { ... UnifiedMotionPayload ... }}`
