# `exp/artifacts/` — Experiment Run Artifacts

## Purpose
Designated local directory for generated outputs, evaluation logs, raw motion tensors, and rendered preview videos produced during experiment runs.

## What Belongs Here
- Local runtime output files generated by scripts in `exp/scripts/`.
- Temporary evaluation logs.

## What Must NOT Belong Here
- Committed binary files (all contents except this README are gitignored).
- Production assets or website code.

## Source-of-Truth Relationship
- Intermediate data captured for subsequent analysis in `exp/reports/`.
