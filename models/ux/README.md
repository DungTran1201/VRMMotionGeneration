# `models/ux/` — UX & Design System Models

## Purpose
Maintains structured design tokens, UI component specifications, layout parameters, and theme definitions.

## What Belongs Here
- Design tokens in JSON/YAML (color scales, spacing units, typography scales, z-indices).
- UI component state and property schemas.
- 3D viewport control default parameters (camera FOV, near/far clipping, orbit damping).

## What Must NOT Belong Here
- Compiled CSS or browser JS code.

## Source-of-Truth Relationship
- Canonical source for `docs/10-ux/` and `diagrams/ux/`.
