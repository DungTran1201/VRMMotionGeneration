# `models/interaction/` — Interaction & State Models

## Purpose
Maintains structured machine-readable definitions of finite state machines, event triggers, transition guards, and protocol sequences.

## What Belongs Here
- Finite state machine specifications in structured YAML/JSON (states, events, transitions).
- Protocol handshake and error recovery sequence models.

## What Must NOT Belong Here
- Application controller code.

## Source-of-Truth Relationship
- Canonical source for `docs/08-behavior/` and `diagrams/state/`.
