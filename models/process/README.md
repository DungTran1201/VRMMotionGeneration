# `models/process/` — Process Models

## Purpose
Maintains structured machine-readable specifications of workflows, avatar verification pipelines, and operational lifecycles.

## What Belongs Here
- YAML/JSON workflow schemas detailing step sequences, inputs, outputs, and validation gates.

## What Must NOT Belong Here
- Procedural application code or binary files.

## Source-of-Truth Relationship
- Canonical source for `docs/03-business-process/` and `diagrams/processes/`.
