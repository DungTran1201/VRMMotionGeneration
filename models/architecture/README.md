# `models/architecture/` — Architecture Models

## Purpose
Maintains structured representations of software components, subsystem interfaces, and architectural boundaries.

## What Belongs Here
- Component interface definitions and dependencies.
- Subsystem schemas and message transport topologies.

## What Must NOT Belong Here
- Application source files or third-party binary libraries.

## Source-of-Truth Relationship
- Canonical source for `docs/05-architecture/` and `diagrams/architecture/`.
