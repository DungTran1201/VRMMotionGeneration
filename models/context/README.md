# `models/context/` — Context Models

## Purpose
Maintains structured YAML/JSON specifications defining system boundaries, external actors, client types, and integration surfaces.

## What Belongs Here
- System actor schemas and external entity definitions.
- Boundary interface definitions.

## What Must NOT Belong Here
- Deep learning model weights or application code.

## Source-of-Truth Relationship
- Canonical source for `docs/00-discovery/` and `diagrams/context/`.
